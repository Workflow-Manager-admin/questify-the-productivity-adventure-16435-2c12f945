## ✨ AI Quest Generation/Enhancement Feature

Questify now supports AI-powered quest generation and rewriting:

- Use the **AI Quest** button in the quest log to create structured RPG questlines based on your goals via OpenAI GPT.
- Enhance any quest with the ✨ button for actionable RPG rewrites.
- All AI usage requires an OpenAI API key to be set in the environment.

### Setup OpenAI API Key

Create an `.env` or `.env.local` in `questify_frontend/` with:

```
VITE_OPENAI_API_KEY=sk-...your-openai-key...
```

Then restart the dev server.
